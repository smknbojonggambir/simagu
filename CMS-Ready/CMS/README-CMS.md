# 📁 Source Code CMS SIMAGU (Frontend & App Logic)

Seluruh source code CMS SIMAGU berada di root directory repository ini untuk mendukung deployment langsung melalui platform seperti Vercel, Netlify, Cloud Run, atau GitHub Pages.

## Teknologi Utama CMS
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Persistence**: LocalStorage Engine + Hybrid Google Sheets Cloud Sync

## Menjalankan secara Lokal
```bash
npm install
npm run dev
```

Aplikasi akan berjalan di `http://localhost:3000`.

## Build untuk Produksi
```bash
npm run build
```
Hasil kompilasi file statis akan berada di folder `dist/`.
